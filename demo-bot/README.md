# Демо-бот онлайн-записи и приема заявок для услуг

Готовое решение для демонстрации клиентам из малого бизнеса (бьюти-сфера, барбершопы, автосервисы, ремонт, консультации).

## Что умеет бот:
1. Интерактивное меню с каталогом услуг и прайсом.
2. Пошаговая FSM-запись: выбор услуги -> выбор даты/времени -> имя -> телефон.
3. Мгновенное сохранение в базу данных SQLite.
4. Мгновенное уведомление администратору в Telegram с кликабельным номером клиента.
5. Админ-панель по команде `/admin` (статистика, последние заявки, сумма).

## Быстрый запуск (2 минуты):
1. Откройте `@BotFather` в Telegram, отправьте `/newbot`, придумайте имя (например: `DemoBookingBot`).
2. Скопируйте токен.
3. Скопируйте `.env.example` в `.env`:
   `cp .env.example .env`
4. Вставьте свой токен и ваш Telegram ID (узнать свой ID можно в боте `@userinfobot`).
5. Запустите:
   `../venv/bin/python main.py`
