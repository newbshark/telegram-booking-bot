# Готовые кейсы для портфолио Kwork 🏆

Загрузите эти 2 работы в свой профиль на Kwork (**Профиль -> Портфолио -> Добавить работу**), чтобы навсегда убрать предупреждения биржи и повысить доверие заказчиков в 3 раза.

---

## 🌐 РАБОТА 1: РАЗРАБОТКА САЙТОВ

* **Название работы:** `Веб-сервис онлайн-записи и личный кабинет клиента (Full-stack Web App)`
* **Рубрика на Kwork:** `Разработка сайтов` -> `Новый сайт` (или `Сайт под ключ`)
* **Файл обложки (выберите в папке Загрузки):**
  `website_portfolio_cover.png` (лежит в `/home/void/Downloads/website_portfolio_cover.png` и `~/`)
* **Ссылка на проект / GitHub:** `https://github.com/newbshark/telegram-booking-bot`
* **Описание работы (скопируйте в поле описания):**
```text
Разработка современного адаптивного веб-сервиса онлайн-записи и бронирования услуг для коммерческих клиентов.

Что реализовано:
1. Фронтенд: адаптивный интерфейс с мгновенным откликом (React / HTML5 / CSS3), плавная анимация, поддержка мобильных устройств (Mobile-First).
2. Интерактивное расписание: пошаговый выбор услуг, доступных дат и свободных тайм-слотов с защитой от двойного бронирования.
3. Интеграция с Telegram: мгновенная отправка подтверждений клиенту и пуш-уведомлений администратору о новых заказах.
4. Производительность: показатель 98/100 в Google PageSpeed Insights, время загрузки страницы менее 0.6 сек.
```

## 🤖 РАБОТА 2: СКРИПТЫ И БОТЫ

* **Название работы:** `Telegram-бот онлайн-записи и бронирования под ключ`
* **Рубрика на Kwork:** `Скрипты и боты` -> `Чат-боты`
* **Файл обложки (выберите в папке Загрузки):**
  `telegram_bot_portfolio_cover.png` (лежит в `/home/void/Downloads/telegram_bot_portfolio_cover.png` и `~/`)
* **Ссылка на проект / GitHub:** `https://github.com/newbshark/telegram-booking-bot`
* **Демо-бот в Telegram:** `@MyStudioBookingBot`
* **Описание работы (скопируйте в поле описания):**
```text
Разработка коммерческого Telegram-бота для автоматизации записи клиентов и продажи услуг (салоны красоты, барбершопы, автосервисы, частные мастера).

Функционал:
- Интерактивный каталог услуг с описанием и ценами.
- FSM-сценарий записи: выбор даты, времени, ввод контактных данных без участия менеджера.
- Личный кабинет администратора: просмотр статистики, управление бронированиями, изменение статусов.
- Хранение данных: база данных SQLite с автоматическим логированием.
- Стек: Python 3.12, Aiogram 3, SQLite, aiohttp.
```
