## 🤖 1. Telegram-бот онлайн-записи (`demo-bot/`)

Готовое коммерческое решение для сферы услуг (барбершопы, автосервисы, бьюти-мастера, частные специалисты, студии):
- 📋 **Интерактивный каталог услуг** с описанием, длительностью и стоимостью.
- 📅 **Пошаговая запись (FSM)**: выбор даты, доступных тайм-слотов, ввод контактов.
- 🔔 **Мгновенные уведомления администратору** при новом заказе с контактами клиента.
- ⚙️ **Админ-панель**: просмотр аналитики, выгрузка записей, смена статусов.

### Быстрый запуск бота:

1. Перейдите в папку бота и создайте виртуальное окружение:
   ```bash
   cd demo-bot
   python3 -m venv venv
   source venv/bin/activate
   pip install -r ../requirements.txt  # или: pip install aiogram python-dotenv
   ```

2. Создайте файл конфигурации `.env`:
   ```bash
   cp .env.example .env
   ```
   Укажите ваш токен от `@BotFather` и Telegram ID:
   ```ini
   BOT_TOKEN=123456789:ABCDefghIJKlmnoPQRstuvwxYZ
   ADMIN_ID=123456789
   ```

3. Запустите бота:
   ```bash
   python main.py
   ```

## 📡 2. Сканер и парсер заказов (`lead-scanner/`)

Позволяет мониторить входящий поток заказов и формировать живые персонализированные отклики:
- Фильтрация спама, вакансий и нерелевантных объявлений.
- Выделение ключевых требований заказчика (бюджет, стек, сроки).
- Генерация естественных, человеческих ответов без шаблонных клише.

Запуск сканера:
```bash
./start.sh
```

- Вся конфиденциальная информация (токены ботов, личные ID, сессии) изолирована в `.env` и исключена из контроля версий через `.gitignore`.
