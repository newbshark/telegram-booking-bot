# Инструкция по запуску скрипта сбора комментариев

Скрипт предназначен для запуска на любом ноутбуке/сервере под управлением **Linux** (Ubuntu, Debian, Arch, Mint, Fedora).

### Быстрый запуск (в 1 команду):

Откройте терминал в папке со скриптом и выполните:
```bash
bash run.sh --url "ССЫЛКА_НА_КНИГУ"
```

Или в интерактивном режиме:
```bash
bash run.sh
```
(скрипт сам спросит ссылку и соберет все комментарии).

### Результат:
- Создается файл `comments.csv` (открывается в Excel, Google Таблицах, LibreOffice Calc).
- Создается файл `comments.json` (для программной обработки).
- Колонки: Автор, Дата, Лайки/Оценка, Текст комментария.
